# Superagent

Operate surface extending the incumbent Unipi shell: existing Inter typography,
warm dark surfaces, shared buttons, SwitchField, phone SheetFrame and conversation
renderer. No new palette, navigation framework or duplicate approval surface.

Desktop: existing sidebar entry, center conversation, 340px independently scrolling
workers/Needs you pane. Phone: the same pane in a full-height shared sheet, opened
from the page header. Chats exposes Superagent in its existing header tools.

Watcher and positive integer concurrency cap are host-owned. Unknown telemetry
shows “Not reported”, never a fabricated zero. Disabled watcher still permits
manual dispatch. Each worker exposes its ticket autonomy, explicit relay, Open and
confirmed Stop. Needs you opens the exact project/ticket; blocked questions wrap.
Review decisions remain in the existing ticket UI; runtime approvals remain in the
shared chat dock. No workspace, autonomy chip, Plan or filesystem plug menu in
Superagent chat. Empty, loading, refresh failure and mutation failure are explicit.
Long lists scroll rather than expanding the page.

## Motion
- Buttons/list rows/inputs: no decorative catalog entry fits dense operational controls; reuse shared hover and instant keyboard focus.
- Switch: reuse SwitchField's existing smooth selection control motion.
- Sheet: reuse SheetFrame's established motion, focus and reduced-motion handling.
- Status values: static updates without count animations.
