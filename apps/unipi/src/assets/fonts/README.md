# Bundled fonts

- `SymbolsNerdFontMono-Regular.woff2` — **Symbols Nerd Font Mono** from the
  Nerd Fonts v3.4.0 release (`NerdFontsSymbolsOnly`), converted from the
  original TTF to WOFF2 with fontTools (no glyph changes). Used only as a
  terminal fallback after JetBrains Mono so Nerd Font glyphs (powerline,
  devicons, Material Design icons, …) render instead of tofu.
  License: MIT, see `SymbolsNerdFontMono-LICENSE.txt`.
  Upstream: https://github.com/ryanoasis/nerd-fonts
