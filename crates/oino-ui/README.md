# oino-ui

Wire types and builder for the Oino extension UI protocol v2 (serde-only,
`wasm32-wasip2`-safe).

* `slot` — registry patches, slots, capabilities, dialog snapshots
* `settings`, `plain`, `limits` — settings namespaces, plain-text rows, tree limits
