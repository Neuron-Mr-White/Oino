# oino-view

Frontend-agnostic view models for Oino clients: transcript, extension UI state, tree,
sessions, composer, keybindings.

* `transcript` — rows rebuilt from session events, matching the interactive chat
* `tree` — entry-tree flattening, search, folding, windowing
* `sessions` — session list view model
* `composer` — multi-line buffer with history and undo
* `keys`, `commands`, `format` — keybindings, slash commands, shared display formatting
