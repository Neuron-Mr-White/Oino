# oino

The Oino command-line binary: interactive (TUI), print, JSON, RPC and ACP modes over
`oino-core`.

```
oino            # interactive TUI
oino -p "..."   # print mode
oino --mode rpc # JSONL RPC over stdio
oino acp        # ACP agent over stdio
```
