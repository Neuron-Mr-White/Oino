## Defaults taken

- `notify` toast placement/ttl is A19's surface (unchanged); `set_editor_text` lands in
  the session's composer draft, which is the undoable path A12 already uses.
- Effects the app has no surface for yet (`openUrl`, `clipboardWrite`, `osNotify`,
  `insertEditorToken`, `openSettings`) are dropped, as §10's degradation allows; only
  `notify` and `set_editor_text` are applied (§3.2's table).
- `custom` dialogs render **docked above the composer** (app.md §3.11 + §3.16.1 supersede
  ui-protocol §3.2's "centred modal" row); their `size` field is therefore unused.
- One `fullscreen` page per extension (§16.1 default = allow, cap 1): the feed keeps the
  first entry of an extension; extra entries stay reachable through the palette command.
- Phone `widget` cap is 3 entries (`+N widgets` expands); status strip 4 segments with the
  rest in the overflow popover (§6.4 caps, §13.6 rule 6).
- Turn footers request only for mounted (visible) turns via U9's render cache; the running
  turn re-asks at most every 500 ms (§6.7).

## Defects found (not this WP's files)

1. **Navigating away from a conversation crashes the shell** — `UniPi hit a problem:
   Cannot read properties of null (reading '<n>')` from Solid's `cleanNode` during the
   conversation unmount. Reproduced with **all U10 pieces disabled** and with the
   non-U10 `timeline-many` scenario (`#/s/pc-coffee/s001` → `#/settings`), so it belongs
   to the conversation/timeline/composer unmount path (A6/A9/A12 owner). It also blocks
   capturing the `/x/:entryId` page after leaving a chat, which is why the ext-page
   screenshots are absent (page render is covered by `slots.test.tsx`).
2. **Phone: the toast stack sits at the bottom** (it overlaps a bottom sheet's header);
   §3.2 wants phone toasts at the top under the safe area (A19).
3. **Phone: the status strip's last segment can run under the capsule chip** (A16
   `status.css` `.status-capsule { top: 60px }` predates the strip row). Mitigated here
   with `padding-right: 76px` on the phone strip; the capsule offset itself is A16's.
4. **Dock composer row is flush to the screen edge on the phone** (the placeholder row is
   half-covered by the dock's 1 px rule/fade). A9/A12 dock chrome, cosmetic.
