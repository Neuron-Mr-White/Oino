# UniPi Oino 1.0.14

This is a small update that fixes two problems reported in 1.0.13.

## A message with images stays one message

- In an idle or new chat, a message with pasted images could briefly appear as two identical bubbles, the first one ending with "Done in 0s". The host always received the message once; only the app showed it twice.
- The app now recognises the live and stored copies of the same message even when images or long text are stored differently, so you see one bubble and one reply.

## Stop works on a scheduled run

- You can now stop a run started by a schedule, from its chat or from the Cron screen. Stop ends the run and the commands it started, instead of leaving a process behind.
- Stopping also works after you close and reopen the app while a scheduled run is in progress.
- While a scheduled run is going, its chat stays read-only with a Stop button. Once you stop it, you can continue in the same chat.
- A stopped run is shown as stopped by you, not as a failure, and does not send a failure notification.

## Installing and updating

Use the assets attached to this release and check `SHA256SUMS`. Linux AppImage, Windows and macOS updater bundles use signed updates. Debian packages use the Download action and your package manager. Android verifies the download checksum and requires the existing release signing certificate. Keep your phone app and desktop/host on matching versions.

macOS builds are ad-hoc signed, not Apple-notarized, and may need right-click → Open on first launch. Desktop updater signatures are separate from operating-system code signing.

## Known limitations

- Running `/kanboard status` while a permission card is open can hide the answer inside the collapsed "Worked for …" section. Answer the permission card, then expand that section to read it.
- Applying or leaving a Fusion pair can reset the thinking level. Check it after switching. A newly created board can leave the open chat's skill count stale even though its board tools work.
- An unknown slash command can remain as an unsent draft without an explanation. Clear it before typing another message.
